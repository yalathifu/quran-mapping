# Qur'an Project

Peta pribadi untuk memahami, menghayati, mengamalkan, dan mengajarkan Al-Qur'an.

Sistem ini bukan buku dan bukan tafsir baru. Ini adalah basis pengetahuan pribadi yang tumbuh bertahap, dengan satu sumber kebenaran per informasi dan banyak pintu masuk yang saling terhubung.

Status proyek saat ini: Level 1 - membangun Al-Fatihah sebagai prototype.
