# Sistem Status

Setiap entri di proyek ini diberi label pada dua dimensi: jenis dan status pengerjaan.

## Dimensi A - Jenis

- Quran
- Hadith
- Tafsir
- Ulama
- Sejarah
- Fiqh
- Bahasa
- Sintesis
- Refleksi pribadi
- Aplikasi

## Dimensi B - Status sumber

- Primary
- Secondary
- Synthesis
- Personal
- Unverified

## Status pengerjaan

- Verified: sudah dicocokkan langsung ke sumber aslinya.
- Needs review: dikutip atau ditulis, tetapi belum dicocokkan ke sumber asli.
- Unverified: belum dicek sama sekali.
- Personal: murni catatan/refleksi pribadi, tidak berlaku status verifikasi sumber.

## Format penulisan

Ditulis mengikuti isi, dalam format:

```
[Jenis / Dimensi-B / Status-pengerjaan]
```

Contoh:

```
Al-Baqarah 2:286 - Tafsir Kemenag
[Tafsir / Secondary / Verified]

"Ayat ini membuat saya sadar bahwa..."
[Refleksi pribadi / Personal / Personal]
```

## Aturan pemakaian status

Needs review dan Unverified tidak dijadikan dasar untuk:
- amal/praktik yang dijalankan sebagai kesimpulan tetap,
- materi yang diajarkan ke orang lain.

Kedua status ini boleh dipakai sebagai catatan sementara sambil menunggu verifikasi, tapi harus tetap terlihat sebagai belum final.
