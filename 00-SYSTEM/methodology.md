# Metodologi

## Tujuan

Membangun sistem belajar pribadi yang menghubungkan:

Ayat - Makna - Struktur - Tema - Hikmah - Sikap - Amal - Kehidupan - Pengajaran

Tidak ada target "selesai 114 surat". Targetnya adalah sistem yang terus tumbuh: setiap hal yang dipelajari punya tempat.

Peran AI dalam proyek ini adalah asisten riset, penyusun, pembanding, dan pengolah informasi. AI bukan sumber agama yang berdiri sendiri dan tidak berwenang memutuskan tafsir mana yang benar ketika ada perbedaan pendapat.

## Prinsip arsitektur

Satu sumber kebenaran, banyak pintu masuk.

- Ayat adalah lokasi sumber.
- Konsep dan tema adalah sintesis lintas lokasi, ditautkan kembali ke ayat, tidak menyalin ulang isinya.
- Kalau ada koreksi, cukup diperbaiki di satu tempat.

## Delapan lapisan (tidak harus semua diisi setiap kali)

1. Pemahaman
2. Struktur
3. Konsep dan tema
4. Tadabbur
5. Hukum dan petunjuk
6. Aplikasi
7. Pembentukan diri
8. Pengajaran (fase belakangan)

Isi hanya lapisan yang relevan untuk pembahasan yang sedang dikerjakan. Jangan memaksakan kelengkapan.

## Kapan file dipecah

Pecah file kalau:
- bagian tersebut sudah terlalu panjang untuk dibaca nyaman dalam satu konteks, atau
- punya fungsi yang jelas berbeda (misalnya tafsir versus tadabbur pribadi).

Jangan pecah file hanya karena secara teknis bisa dibuat file sendiri. Untuk surat pendek (seperti Al-Fatihah), satu file ayat-map masih nyaman dipakai. Untuk surat panjang (seperti Al-Baqarah), baru dipecah per kelompok ayat (sections/).

## Level pengerjaan

| Level | Isi |
|---|---|
| 0 - Foundation | Sistem sumber, aturan, template (dokumen di 00-SYSTEM ini) |
| 1 - Al-Fatihah | Prototype lengkap untuk menguji format |
| 2 - 5 Surat | Al-Fatihah, Al-Baqarah, Ali Imran, An-Nisa, Al-Ma'idah |
| 3 - Thematic Engine | Konsep lintas surat (sabar, taqwa, tawakal, dst) |
| 4 - 30 Juz | Master map mulai terbentuk, tidak perlu detail penuh |
| 5 - Deep Dive | Pendalaman surat/ayat/tema tertentu sesuai minat, tanpa batas waktu |

Struktur folder tidak dikunci di Level 0. Al-Fatihah dipakai sebagai uji coba selama beberapa waktu; bagian yang terbukti berguna baru dijadikan standar untuk surat berikutnya.
